# Dev-only — not shipped

Real shadcn ui primitives (`components/ui/*`, `lib/utils.ts`), generated by
`npx shadcn@latest add …` into a throwaway Next.js app and copied here
verbatim, purely so `registry/brand-editor`'s `@/*` imports resolve for this
monorepo's own `tsc`/`vitest` runs (see `../tsconfig.json`'s `paths` and
`packages/brand-editor/vitest.config.ts`'s `resolve.alias`).

Not part of the published package — absent from `package.json`'s `files`
array on purpose. A real consumer gets their own copies of these files from
`npx shadcn add` against their own project's base (Base UI, Radix, or React
Aria — see `registry/brand-editor/README.md`), not from here.

If shadcn's registry format or component APIs move again, regenerate this
folder against a fresh `shadcn init`/`add` rather than hand-editing it.
